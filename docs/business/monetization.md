# Monetization

These tiers and prices are hypotheses. Validate demand, cost to serve, and willingness to pay before offering subscriptions.

| Tier         | Price hypothesis         | Intended value                                     |
| ------------ | ------------------------ | -------------------------------------------------- |
| Free         | $0                       | Browser-based manual utilities                     |
| Professional | Approximately $12/month  | Advanced individual workflows and automation       |
| Team         | Approximately $49/month  | Shared workflows and collaboration                 |
| Business     | Approximately $99+/month | Operational monitoring and higher-volume workflows |

The first target is $50 in monthly recurring revenue. Test whether users return for a recurring problem and which paid workflow they would adopt. Pricing and entitlement implementation belong to a future phase.
